# 🎓 Smart Classroom Feedback System

A web-based **Smart Classroom Feedback System** developed using **PHP and MySQL**.  
The system allows students to submit feedback about faculty and subjects, while administrators can manage and analyze the submitted feedback.

---

## 📌 Project Overview

The Smart Classroom Feedback System is designed to digitize the traditional classroom feedback process.

Students can:

- Register and login
- Select faculty and subject
- Submit feedback
- View submitted feedback
- Edit feedback
- Delete feedback

Administrators can:

- Login securely
- View dashboard statistics
- View all student feedback
- Generate faculty-wise feedback reports

---
